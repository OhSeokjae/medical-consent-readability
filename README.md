# ICF Readability Analysis

임상시험 동의서(Informed Consent Form)의 가독성을 한국어 이독성 공식 및 의학 전문용어 분석을 통해 정량적으로 지표화하고, KGCP 기준 필수항목 완전성을 평가하며, LLM 기반으로 이해하기 쉬운 동의서로 자동 개선하는 파이프라인

## 연구 배경

임상시험 참여자는 동의서를 통해 연구의 목적, 위험, 이익 등을 충분히 이해한 후 자발적으로 참여를 결정해야 한다(KGCP 제7호아목10) **[R7]**). 그러나 국내 연구 **[R2]** 에 따르면 실제 동의서는 평균 260문장, 15페이지 분량으로 평이한 어휘가 약 12% 부족하고 전문용어가 약 4.5% 과다하여 일반인의 자기결정권 행사를 저해하고 있다. 참여자 관점에서도 기본 임상시험 개념을 충분히 이해하지 못하며, 어려움을 연구자에게 적극적으로 소통하지 않는 것으로 나타났다 **[R9]**. 국제적으로도 ICF의 평균 가독성 수준은 대학 수준(Flesch-Kincaid 10.6 grade level)으로, 권장 기준(≤8th grade)을 크게 상회한다 **[R5]**.

본 연구는 한국어 전용 이독성 공식 **[R1]**, 국립국어원 기초어휘 등급 **[R4]**, 의학 전문용어 난이도 세분화 **[R6]** 를 결합하여 임상시험 동의서의 가독성을 정량적으로 평가하고, AI 기반으로 개선하는 자동화 파이프라인을 구축한다.

## 연구 목표

1. 한국어 임상시험 동의서의 가독성을 이독성 공식 **[R1]** 기반 학년 수준으로 정량 측정
2. 의학 전문용어 난이도 세분화 분석 (사전 매칭 + MedReadMe **[R6]** 방법론)
3. KGCP **[R7]** 기반 필수항목(20개) 완전성 자동 평가
4. LLM(GPT-4o)을 활용한 동의서 평이화 (목표: 중학교 2학년 수준, ICF 국제 권장 ≤8th grade **[R5]**)

## 파이프라인

```
CRIS 데이터 수집 (공공데이터 API)
    → 모의 ICF 생성 (GPT-4o, 배치 분할)
        → 가독성 지표화 (이독성 공식 + 전문용어 분석)
            → 완전성 분류 (KoBERT)
                → 평이화 (GPT-4o)
                    → 평이화 전후 비교 분석 → 리포트
```

## 실험 설계

### Phase 1: 모의 데이터 기반 파이프라인 구축
- CRIS(임상연구정보서비스) 공공데이터 API에서 중재연구 8,785건 수집
- GPT-4o로 수집된 정보 기반 모의 동의서 50건 생성 (KGCP 20개 항목 포함, 건당 ~14,000자)
- 전체 파이프라인 검증 (가독성 평가, 완전성 분류, 평이화)

### Phase 2: 실제 데이터 기반 본 실험
- IRB 승인된 실제 동의서를 기관 협조 등으로 확보 (오프라인)
- 동일 파이프라인에 실제 데이터를 투입하여 본 실험 수행

## 가독성 지표화 프레임워크

### 전체 구조

```
동의서 원문 텍스트 (섹션별 20개 KGCP 항목)
        │
        ▼
┌──────────────────────────────┐
│     전처리 레이어              │
│  MeCab-ko 형태소 분석          │
│  문장 분리 (kss) / 어절 분리    │
│  의학용어 사용자 사전 적용       │
└──────────┬───────────────────┘
           │
     ┌─────┼─────┐
     ▼     ▼     ▼
   문장   어휘   전문용어        ← 개별 지표 측정 (A·B·C)
   지표   지표   분석
     │     │     │
     └─────┼─────┘
           ▼
     이독성 공식 (학년 수준)     ← 한국어 전용 공식 [R1]
           │
           ▼
     종합 가독성 점수 (0-100)   ← 가중합 정규화
           │
           ▼
     난이도 등급 판정            ← Easy / Moderate / Difficult
```

### 전처리 레이어

| 구성 요소 | 도구 | 역할 |
|-----------|------|------|
| 형태소 분석기 | MeCab-ko (은전한닢) | 어절 → 형태소 분리, 품사(POS) 태깅 |
| 문장 분리기 | kss (Korean Sentence Splitter) | 문장 경계 인식 |
| 사용자 사전 | MeCab 사용자 사전에 의학용어 등록 | "이중맹검", "약동학" 등 복합어 인식률 향상 |

### A. 문장 수준 지표 — 구문 복잡도

이독성 공식 **[R1]** 의 핵심 변수인 평균 문장 길이를 중심으로, ICF 가독성 연구 **[R2]** 에서 확인된 문장 복잡도 지표를 측정한다.

| 지표 | 측정 방법 | Easy | Difficult | 근거 |
|------|-----------|------|-----------|------|
| **평균 문장 길이** | 문장당 어절 수 평균 | ≤15 | ≥25 | **[R1]** 이독성 공식 핵심 변수, **[R2]** ICF 문장 분석 |
| 최장 문장 길이 | 가장 긴 문장의 어절 수 | — | — | 극단값 탐지 |
| 문장당 절 수 | 내포절·접속절 수 평균 | ≤2 | ≥4 | 구문 복잡도 |

### B. 어휘 수준 지표 — 어휘 난이도

이독성 공식 **[R1]** 의 다른 핵심 변수인 쉬운 단어 비율을 국립국어원 기초어휘 목록 **[R4]** 으로 산출하고, ICF 특화 지표로 한자어 비율 **[R2]** 을 추가 측정한다.

| 지표 | 측정 방법 | Easy | Difficult | 근거 |
|------|-----------|------|-----------|------|
| **쉬운 단어 비율** | 국립국어원 기초어휘 1-2등급 비율 | ≥75% | ≤50% | **[R1]** 이독성 공식 핵심 변수, **[R4]** 기초어휘 등급 |
| 한자어 비율 | 한자어 어휘 / 전체 어휘 | ≤30% | ≥50% | **[R2]** ICF 어휘 수준 분석 |
| TTR (어휘 다양성) | 고유 어휘 수 / 전체 어휘 수 | — | — | 보조 지표 |
| 어절당 형태소 수 | 형태소 분석 결과 평균 | ≤2.5 | ≥4.0 | 형태적 복잡도 |
| 피동·사동 비율 | -이/히/리/기/우/추 포함 비율 | — | — | 문법적 복잡도 |

### C. 의학 전문용어 분석 — 도메인 특화 난이도

기존 이독성 연구 **[R1]** 에는 없는, ICF 도메인에 특화된 분석 레이어. MedReadMe **[R6]** 의 전문용어 난이도 세분화 방법론과, ICF 가독성 연구 **[R2]** 의 전문용어 비율 분석을 결합한다.

#### C-1. 사전 기반 매칭 (Dictionary Lookup)

```
형태소 분석 결과 → 의학용어 사전 대조 → 전문용어 여부 판정
```

| 사전 자원 | 규모 | 비고 |
|-----------|------|------|
| HIRA 보건의료 용어사전 | 공공데이터 | 기본 용어 확보 |
| ICF 빈출 용어 자체 추출 | 동의서 말뭉치 기반 | 도메인 최적화 |
| KMLE 의학검색엔진 | 239,916 용어 | 웹 검색 보완 |

#### C-2. 전문용어 난이도 세분화 **[R6]**

MedReadMe **[R6]** 의 방법론을 차용하여, 단순 "있다/없다"가 아니라 이해 난이도별 4단계로 분류. 한국 임상시험 참여자가 기본 개념을 이해하지 못하는 실태 **[R9]** 를 고려하여, Google-Hard 및 Abbreviation 분류를 핵심 지표로 활용한다.

| 분류 | 정의 | 예시 |
|------|------|------|
| Google-Easy | 검색으로 쉽게 이해 가능 | "혈압", "CT 촬영", "항생제" |
| Google-Hard | 전문 지식 없으면 이해 곤란 | "약동학적 생동성", "이중맹검" |
| Abbreviation | 설명 없는 약어 | "IRB", "AE", "SAE", "CRF" |
| General Complex | 비의학 어려운 일반어 | "무작위배정", "인과관계" |

#### C-3. 전문용어 산출 지표

| 지표 | 산출 방법 | Easy | Difficult |
|------|-----------|------|-----------|
| `tech_term_ratio` | 의학용어 매칭 어절 / 전체 어절 | ≤5% | ≥15% | **[R2]** |
| `jargon_span_count` | 전문용어 span 총 개수 | — | — | **[R6]** |
| `hard_jargon_ratio` | Google-Hard 비율 | — | — | **[R6]** |
| `abbreviation_count` | 미설명 약어 수 | — | — | **[R6]** |
| `jargon_density` | 문장당 평균 전문용어 수 | — | — | **[R6]** |

> **[R6]** MedReadMe 핵심 발견: 기존 이독성 공식에 `jargon_span_count` 하나만 추가해도 사람의 난이도 판단과의 상관관계가 유의하게 향상

### 이독성 공식 — 학년 수준 산출 **[R1]**

이순영(2017) **[R1]** 의 한국어 전용 이독성 공식. 영어 Flesch-Kincaid Grade Level **[R5]** 에 대응하되, 음절 수 대신 국립국어원 기초어휘 **[R4]** 기반 "쉬운 단어 비율"을 사용하는 것이 핵심 차이:

```
학년 수준 = 4.874 + (0.591 × 평균 문장 길이) − (9.201 × 쉬운 단어 비율)
```

| 입력 변수 | 출처 | 예시값 |
|-----------|------|--------|
| 평균 문장 길이 (어절 수) | A 레이어 | 20 |
| 쉬운 단어 비율 (0~1) | B 레이어 | 0.60 |
| → **학년 수준** | | **10.3** (= 고1 수준) |

### 종합 가독성 점수 (0-100, 높을수록 읽기 쉬움)

| 구성 요소 | 가중치 | 방향 | 근거 |
|-----------|--------|------|------|
| 이독성 공식 학년 수준 | 30% | 역변환 (학년 낮을수록 ↑) | **[R1]** |
| 쉬운 단어 비율 | 25% | 정변환 (비율 높을수록 ↑) | **[R1]**, **[R4]** |
| 평균 문장 길이 | 20% | 역변환 (짧을수록 ↑) | **[R1]**, **[R2]** |
| 의학 전문용어 비율 | 15% | 역변환 (적을수록 ↑) | **[R2]**, **[R6]** |
| 한자어 비율 | 10% | 역변환 (적을수록 ↑) | **[R2]** |

### 난이도 등급 판정

| 등급 | 종합 점수 | 학년 수준 | 의미 |
|------|-----------|-----------|------|
| **Easy** | 70 ~ 100 | ≤ 중2 (≤8) | 일반 시민 이해 가능 — ICF 국제 권장 수준 **[R5]** |
| **Moderate** | 40 ~ 69 | 고교 (9~12) | 교육받은 성인 수준 |
| **Difficult** | 0 ~ 39 | ≥ 대학 (13+) | 전문가 수준 — 일반인 이해 곤란 |

### 분석 단위

| 분석 단위 | 대상 | 목적 |
|-----------|------|------|
| 동의서 전체 | ICF 1건 전체 텍스트 | 문서 간 비교, 전체 난이도 파악 |
| 섹션별 | KGCP 20개 항목 각각 | 항목별 난이도 편차 분석 |

## KGCP 필수항목 (20개)

KGCP 제7호아목10) **[R7]** 에 따른 동의설명서 필수 기재사항:

| # | 조항 | 항목 |
|---|------|------|
| 1 | 가) | 임상시험이 연구 목적으로 수행된다는 사실 |
| 2 | 나) | 임상시험의 목적 |
| 3 | 다) | 임상시험용 의약품 정보 및 시험군/대조군 무작위배정 확률 |
| 4 | 라) | 침습적 시술 포함 각종 검사나 절차 |
| 5 | 마) | 대상자가 준수하여야 할 사항 |
| 6 | 바) | 검증되지 않은 임상시험이라는 사실 |
| 7 | 사) | 예상되는 위험이나 불편 |
| 8 | 아) | 기대되는 이익 또는 이익이 없다는 사실 |
| 9 | 자) | 대체 치료방법 및 그 위험과 이익 |
| 10 | 차) | 손상 발생 시 보상이나 치료 |
| 11 | 카) | 참여에 따른 금전적 보상 |
| 12 | 타) | 참여에 따른 예상 비용 |
| 13 | 파) | 참여는 자발적이며, 거부/중단해도 불이익 없음 |
| 14 | 하) | 모니터요원, 점검자, IRB, 규제기관의 기록 열람 가능성 |
| 15 | 거) | 신상 기록의 비밀 보호 |
| 16 | 너) | 참여 여부에 영향을 줄 새로운 정보의 적시 전달 |
| 17 | 더) | 추가 정보 필요 시 또는 피해 발생 시 문의처 |
| 18 | 러) | 임상시험 참여 중지 경우 및 사유 |
| 19 | 머) | 예상 참여 기간 |
| 20 | 버) | 참여하는 대략의 대상자 수 |

## 모델

- **KoBERT** (`monologg/kobert`): 완전성 분류 (20-label multi-label) 및 복잡도 분류 (3-class)
- **GPT-4o**: 모의 동의서 생성 (배치 분할, 건당 ~14,000자) 및 평이화

## 근거 연구

### [R1] 이순영(2017), "글의 수준을 평가하는 국어 이독성 공식"

- **출처**: 독서연구, 제44호, 한국독서학회
- **링크**: https://kiss.kstudy.com/thesis/thesis-view.asp?key=3482213
- **내용**: 초등~고등 국어 교과서 텍스트를 기반으로 한국어 전용 이독성(readability) 공식을 개발. 기준 텍스트 선정 → 언어 변수 확인 → 상관분석 → 회귀분석의 4단계를 거쳐 공식을 도출하고, EasyWord 1.0 프로그램으로 구현. 영어의 Flesch-Kincaid Grade Level에 대응하는 한국어 공식으로, 음절 수 대신 "쉬운 단어 비율"을 사용한 것이 핵심.
- **차용 요소 및 적용 위치**:
  - `학년 수준 = 4.874 + (0.591 × 평균 문장 길이) − (9.201 × 쉬운 단어 비율)` → **이독성 공식 레이어** 전체
  - 평균 문장 길이 (어절 수) → **A. 문장 수준 지표**
  - 쉬운 단어 비율 → **B. 어휘 수준 지표**
  - 학년 수준 기반 난이도 판정 → **난이도 등급 판정** 체계
  - 종합 가독성 점수 가중치 30% (학년 수준) + 25% (쉬운 단어 비율) + 20% (문장 길이) → **종합 점수 산출**

### [R2] 최임순, 이인향, 용철순(2016), "임상시험 시험대상자설명서의 가독성 평가"

- **출처**: 대한임상약학회지 (Korean Journal of Clinical Pharmacy), 제26권 제1호, pp.33-39
- **링크**: https://www.ekjcp.org/journal/download_pdf.php?spage=33&volume=26&number=1
- **내용**: 국내 임상시험 동의서의 어휘 수준을 정량 분석한 연구. 실제 ICF를 대상으로 평이한 어휘 비율, 전문용어 비율, 한자어 비율을 측정하고 국어 교과서와 비교. 결과: 평균 260문장, ~15페이지, 평이한 어휘 ~12% 부족, 전문용어 ~4.5% 과다, 교과서 대비 어휘 수준 유의한 차이(p < 0.001).
- **차용 요소 및 적용 위치**:
  - 전문용어 비율 측정 방법론 → **B. 어휘 수준 지표** (`tech_term_ratio`)
  - 한자어 비율 측정 방법론 → **B. 어휘 수준 지표** (`sino_korean_ratio`)
  - 평균 문장 길이 기준 → **A. 문장 수준 지표** (`avg_sentence_length`)
  - ICF 실태 벤치마크 수치 (260문장, 15페이지) → **연구 배경**
  - 종합 가독성 점수 가중치 15% (전문용어) + 10% (한자어) → **종합 점수 산출**

### [R3] Lee & Lee(2023), "KRIT: a Korean Readability Index with a Hybrid Transformer"

- **출처**: KAIST (Korea Advanced Institute of Science and Technology)
- **링크**: https://koasas.kaist.ac.kr/handle/10203/309526
- **내용**: BERT 기반 한국어 가독성 자동 평가 모델. 초등~고등 교과서 25,449문장을 4등급으로 분류하여 학습. 문법 구조와 어휘 의미를 동시에 고려하는 transformer encoder 활용. 정확도 0.746, MAE 0.327. 한국어 가독성에 딥러닝 NLP를 적용한 최초 시도.
- **차용 요소 및 적용 위치**:

  - 교과서 학년별 텍스트 난이도 분류 체계 → **난이도 등급 판정** 설계 참고

### [R4] 국립국어원(2023), "국어 기초 어휘 선정 및 어휘 등급화 연구"

- **출처**: 국립국어원 연구보고서 (2017~2023, 6개년 사업)

- **내용**: 2억 어절 규모의 구어·문어 말뭉치를 기반으로, 연령과 정규교육 학령에 따라 국민이 습득·사용하는 한국어 어휘를 5등급으로 분류. 총 4만 개 기초어휘 목록 구축. 1등급(초등 저학년)~5등급(전문/고급)으로 등급화.

### [R5] Paasche-Orlow et al.(2003), "Readability Standards for Informed-Consent Forms as Compared with Actual Readability"
