# 사전 리소스

## 기초어휘 목록 (`easy_words.txt`)
- 출처: 국립국어원(2023) "국어 기초 어휘 선정 및 어휘 등급화 연구" [R4]
- 형식: 한 줄에 하나의 어휘 (탭 구분: 어휘\t등급)
- 등급: 1(초등 저학년) ~ 5(전문/고급), 1-2등급을 "쉬운 단어"로 사용
- 현재: 시드 목록 (~2,000어) / 목표: 전체 4만 어휘

## 의학용어 사전 (`medical_terms.txt`)

- 형식: 한 줄에 하나의 의학용어
- 현재: 시드 목록 (~500어) / 목표: 전체 76,733어
